# CeilPlan

현장 조건과 사용자 입력을 바탕으로
천장 자재의 예상 필요 수량과 발주 금액을 계산하는
개인 포트폴리오 프로젝트입니다.

Next.js App Router, TypeScript, Tailwind를 사용합니다.

## 실행

```sh
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 빠르게 체험하기

1. 상단의 ‘예시 프로젝트 불러오기’를 누릅니다.
2. ‘예상 자재 계산하기’를 누릅니다.
3. 자재별 ‘계산 근거 보기’를 펼칩니다.
4. 조정값이나 Loss를 변경하고 다시 계산합니다.
5. JSON 백업과 CSV 다운로드를 확인합니다.

예시의 모든 수치는 기능 체험과 검산을 위한 가상 입력입니다.
공식 시공 기준, 권장 규격 또는 실제 시장 단가가 아닙니다.

예시는 자동으로 저장되지 않습니다.
보관하려면 프로젝트 저장 버튼을 누르세요.

## 현재 구현

- 현장 기본 정보와 자재 조건 입력
- 석고보드·M-BAR·캐링의 면적 기반 예상 물량
- 사용자 입력 현장 추가·공제
- Loss와 구매 단위 올림 분리
- 예상 발주 수량과 사용자 단가 기반 금액
- SVG 공간·현장 요소 표시
- 계산 당시 입력과 결과 Snapshot
- 자재별 계산 근거 상세보기
- 프로젝트 브라우저 저장·불러오기
- 프로젝트 JSON 백업·복원
- Snapshot 결과 CSV 다운로드
- 입력 변경 및 결과 복원 시 재계산 필요 표시

간격·규격·Loss·정척·단가는 사용자가 입력합니다.
현장 요소의 자동 공제·보강 공식은 제공하지 않습니다.

현재 입력과 마지막 계산 Snapshot은 서로 다를 수 있습니다.
가져오거나 복원한 계산 결과는 다시 계산한 뒤 사용합니다.

브라우저 저장은 다른 기기와 동기화되지 않습니다.
JSON 파일로 프로젝트를 백업할 수 있습니다.
