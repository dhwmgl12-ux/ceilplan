# CeilPlan

현장 조건과 사용자 입력을 바탕으로
천장 자재의 예상 필요 수량과 발주 금액을 계산하는
개인 포트폴리오 프로젝트입니다.

Next.js App Router, TypeScript, Tailwind를 사용합니다.

## 실행

```sh
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 빠르게 체험하기

1. 첫 화면에서 ‘예시로 체험하기’를 누릅니다.
   작업 중에는 상단 ‘추가 작업 → 예시 프로젝트 불러오기’를 사용할 수 있습니다.
2. ‘예상 자재 계산하기’를 누릅니다.
3. 결과 영역의 ‘자재별 계산 근거’를 펼칩니다.
4. 조정값·Loss·단가를 변경하고 다시 계산합니다.
5. 프로젝트를 수동 저장하거나 JSON으로 백업합니다.
6. 계산 완료 결과는 CSV 또는 발주용 보기로 확인합니다.

예시 수치는 기능 체험과 검산용입니다.
공식 시공 기준·권장 규격·실제 시장 단가가 아닙니다.

예시는 프로젝트 목록에 자동 등록되지 않습니다.
보관하려면 ‘프로젝트 저장’을 누르세요.
자동 임시저장은 프로젝트 수동 저장과 별개입니다.

여러 공간은 `/housing`에서 관리합니다.
프로젝트 → 세대 타입 → 한 세대의 공간 순서로 구성합니다.

## 현재 구현

- 직사각형·ㄱ자·ㄷ자 공간과 치수 입력
- 캔버스 중심 레이아웃과 입력·결과 패널 전환
- 요소 클릭·터치 배치, 선택, 이동과 숫자 기반 속성 수정
- 실행 취소·다시 실행, 복제·반복 배치와 사용자 템플릿
- 도면 이미지 배경을 참고한 수동 입력
- 사용자 입력 현장 추가·공제, Loss와 구매 단위 올림
- 예상 수량·금액과 계산 당시 Snapshot
- 자재별 계산 근거와 계산안 저장·비교
- 프로젝트 저장·검색·불러오기와 자동 임시저장·복구
- JSON 백업·복원, 결과 CSV와 공간별 발주용 인쇄
- 세대 타입·여러 공간 관리와 전체 계산·CSV
- 미적용 입력·미저장 변경·재계산 필요 상태 구분

기타 자재·사용자 단가표는 기반 모듈 단계입니다.
현재 입력 화면과 전체 결과 합계에는 연결되지 않았습니다.

## 현재 제한

- 면적 기반 예상 물량이며 실제 부재 배치·절단·잔재 최적화는 제공하지 않습니다.
- 현장 요소를 등록하는 것만으로 자재를 자동 공제·보강하지 않습니다.
- 미적용 폼 입력은 프로젝트 저장·JSON·자동 임시저장 대상이 아닙니다.
- 공간 전환 시 편집 이력과 미적용 입력, 도면 배경은 초기화됩니다.
- 도면 배경 이미지는 프로젝트 저장·JSON·인쇄에 포함되지 않습니다.
- 요소 템플릿과 계산안 목록은 프로젝트 JSON에 포함되지 않는 별도 브라우저 데이터입니다.
- 발주용 인쇄와 계산안 비교는 공간 한 개 기준입니다.
- 로그인·서버 저장·기기 간 동기화는 지원하지 않습니다.
