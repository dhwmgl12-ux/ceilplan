# 배포 전 검증

## 검증 환경과 대상

- 검증 날짜: 미기록
- 검사한 커밋 또는 브랜치: 미기록
- 미커밋 변경 포함 여부: 미기록
- 운영체제: 미기록
- Node.js 버전: 미기록
- 브라우저와 버전: 미기록
- 실행 방식: 개발 모드 / 빌드 후 실행 중 기록
- 확인한 화면 크기: 미기록
- 검증자: 미기록

## 기록 원칙

- 실제로 확인한 항목만 체크한다.
- 결과는 통과·실패·미실행으로 구분한다.
- 실패 항목은 재현 방법과 함께 기록한다.
- 수정 후에는 해당 실패 사례를 다시 확인한다.
- 개발 모드 확인과 빌드 후 실행 확인을 구분한다.
- 체크리스트 완료는 공식 시공 기준 검증을 의미하지 않는다.
