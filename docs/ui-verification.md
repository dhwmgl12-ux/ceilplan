## 접근성과 오류

- [ ] Tab으로 주요 입력·버튼·펼쳐보기 접근
- [ ] 포커스 표시가 잘리지 않음
- [ ] Enter·Space로 도구와 요소 선택 가능
- [ ] 계산 오류 후 보이는 영역으로 포커스 이동
- [ ] 발주용 보기 닫기·Esc·포커스 복귀 확인
- [ ] 긴 프로젝트명·조정 사유로 화면이 깨지지 않음
- [ ] 하단 계산 버튼이 마지막 콘텐츠를 가리지 않음
- [ ] 존재하지 않는 주소에서 404 화면 확인
- [ ] 콘솔에 주요 런타임 오류·중복 key 경고 없음

## 판정 원칙

- 실제 확인한 항목만 통과 처리한다.
- 미실행·실패·통과를 구분한다.
- 수정 후에는 실패 사례를 다시 검증한다.
- 체크되지 않은 항목을 완료로 간주하지 않는다.
- 기능 검증은 공식 시공 기준 검증을 의미하지 않는다.
