# CeilPlan 작업 화면 기준

## 1. 목적과 적용 범위

확정한 UI 시안의 화면 구조를 기존 CeilPlan에 적용한다.

이번 작업은 기존 기능의 재배치와 사용 흐름 개선이다.
계산 공식, 실제 좌표 기준, 프로젝트 저장 형식은 유지한다.

이미지는 배치·스타일 참고 자료다.
이미지에 표시된 도형 비율과 치수는 구현 기준으로 사용하지 않는다.

이 문서는 목표 화면과 동작 기준이며,
작성했다는 이유만으로 구현·검증 완료로 간주하지 않는다.

## 2. 공통 화면 구조

- 상단: 프로젝트명, 프로젝트 저장 상태, 주요 명령
- 작업 탭: 공간·자재 설정 / 요소 편집 / 산출 검토
- 본문: 현재 작업에 필요한 패널과 캔버스 또는 결과
- 하단: 작업 모드, 단위, 계산 상태, 복구용 임시저장 상태

데스크톱에서는 긴 패널을 내부 스크롤한다.
캔버스가 긴 입력 폼 때문에 화면 밖으로 밀리지 않도록 구성한다.

작은 화면에서는 패널을 전환해서 사용한다.
정확한 편집에 필요한 입력과 기능을 제거하지 않는다.

## 3. 작업 탭별 기능 배치

### 공간·자재 설정

- 공간명과 형태
- 전체 치수와 제외 영역
- M-BAR·캐링 간격
- 석고보드 규격과 겹수
- Loss
- 구매 정척과 단가
- 공간 미리보기
- 입력 오류와 안내

### 요소 편집

왼쪽:

- 현재 작업 공간 선택
- 공간 관리 진입점
- 공간 치수 요약
- 현장 요소 추가
- 요소 목록과 개별 선택
- 선택 요소 복제·반복 배치
- 사용자 템플릿 접근

가운데:

- 선택·배치·이동 도구
- 실행 취소·다시 실행
- SVG 캔버스
- 도면 배경 설정 접근

오른쪽:

- 선택 요소의 종류·위치·크기
- 속성 적용·취소
- 연결된 조정값 목록
- 조정값 추가·수정·삭제

요소 추가와 선택 요소에 수행하는 명령은 구분한다.
선택하지 않은 상태에서는 짧은 선택 안내를 표시한다.

### 산출 검토

- 현재 결과의 계산 시각과 최신 여부
- 예상 발주 수량과 합계 금액
- 상세 수량과 자재별 계산 근거
- 검토할 항목
- 계산안 저장·비교
- CSV·발주용 보기·인쇄

다중 공간에서는 선택 공간 결과와 프로젝트 전체 결과를 구분한다.

## 4. 프로젝트 명령

상단에 열기·저장·계산·결과 보기를 배치한다.

새 프로젝트·예시·JSON 입출력은 추가 메뉴에서 접근할 수 있다.
기존 기능을 화면 정리를 이유로 제거하지 않는다.

새 프로젝트·불러오기·복구 후에는 공간·자재 설정 탭을 연다.
저장 데이터의 기존 ID 처리와 복원 정책은 유지한다.

계산은 적용된 입력만 사용한다.
계산 성공 후 산출 검토 탭으로 이동한다.

입력 검증 실패 시 해당 입력이 있는 탭과 접힌 영역을 열고,
오류 입력 또는 오류 목록으로 포커스를 이동한다.

## 5. 탭 전환과 상태 유지

작업 탭은 순서대로 완료해야 하는 단계가 아니다.
사용자가 자유롭게 전환할 수 있다.

같은 프로젝트·같은 공간에서 탭을 전환할 때 다음을 유지한다.

- 적용된 입력
- 선택 요소
- 미적용 폼 입력
- 편집 이력
- 도면 배경
- 마지막 계산 Snapshot

화면에 보이지 않는다는 이유로 상태를 가진 컴포넌트를
제거하거나 새로운 key로 초기화하지 않는다.

같은 상태ful 컴포넌트를 탭마다 중복 생성하지 않는다.
컴포넌트를 다른 부모 아래로 옮겨 재생성하는 방식도 피한다.

다중 공간의 실제 공간 전환은 기존 정책을 유지한다.
적용된 입력을 먼저 읽어 보관하고,
편집 이력·미적용 입력·도면 배경은 초기화될 수 있음을 안내한다.

## 6. 속성 수정과 조정값

속성 입력 중에는 적용된 기존 값으로 도면을 표시한다.
입력만 바꿔놓은 값을 도면이나 계산에 섞지 않는다.

속성 적용:

- 공간 범위와 숫자를 검증한다.
- 수정 중 원본 변경 여부를 확인한다.
- 성공한 변경은 기존 편집 이력에 반영한다.

속성 취소:

- 선택 요소의 미적용 입력을 버리고 최신 적용값을 표시한다.

속성과 조정값은 별도로 검증·적용한다.
속성 적용 버튼이 조정값까지 적용하는 것처럼 표현하지 않는다.

조정값에는 대상 자재·추가/공제·수량·단위·사유를 표시한다.
현재 수동 조정값의 근거는 사용자 입력이다.

요소 배치·크기 변경만으로 자재를 자동 공제·보강하지 않는다.
참고 면적을 제공하더라도 실제 적용 조정값과 구분한다.

## 7. 좌표와 캔버스

내부 길이 단위는 mm를 유지한다.
요소 X·Y는 공간 왼쪽 위를 원점으로 한 요소 왼쪽 위 좌표다.

기존 클릭 배치는 클릭한 지점을 요소 중심으로 처리한다.
배치 결과는 기존 규칙에 따라 왼쪽 위 좌표로 변환한다.

SVG 도형과 치수선은 같은 입력 좌표·배율로 생성한다.
화면 너비와 패널 표시 상태가 바뀌어도 실제 좌표는 바뀌지 않는다.

선택 테두리는 표시이며,
실제 크기 조절 기능이 없는 핸들을 작동 가능한 것처럼 표시하지 않는다.

## 8. 상태 표시

### 미적용 입력

폼에서 편집했지만 아직 추가·수정 적용하지 않은 값이다.
계산·프로젝트 저장·JSON·자동 임시저장 대상이 아니다.

### 프로젝트 미저장

프로젝트에 적용됐지만 수동 저장하지 않은 변경이다.
미적용 입력과 별도로 관리한다.

### 계산 상태

- 결과 없음
- 적용된 입력 기준 최신
- 재계산 필요

미적용 입력이 있으면 결과가 해당 입력을 제외한다는 안내를 제공한다.
적용된 계산 관련 데이터가 바뀌면 기존 stale 처리 정책을 유지한다.

재계산 필요 상태에서는:

- 이전 결과임을 표시한다.
- 결과 이동 명령을 '이전 결과 보기'로 표시한다.
- CSV와 발주용 보기를 비활성화한다.
- 재계산을 주요 행동으로 표시한다.

### 복구용 임시저장

마지막 임시저장 시각과 복구 상태를 표시한다.
프로젝트 수동 저장 완료와 같은 표현을 사용하지 않는다.

복구할 임시본과 임시저장 오류는 눈에 띄게 표시한다.
정상 상태는 짧게 표시한다.

## 9. 다중 공간 연결

단일 공간과 다중 공간의 기존 진입 경로를 유지한다.
공간 선택과 타입·공간 관리 기능의 접근 경로를 제공한다.

현재 공간의 최신 적용 입력을 읽는 기존 흐름을 보존한다.
전체 계산의 공간별 발주 올림·세대 수 적용 정책은 변경하지 않는다.

## 10. 이번 작업에서 추가하지 않는 기능

- 사용자 줌·팬·스냅·측정
- 회전
- 자유형 다각형 공간
- 우물천장 등 미구현 요소
- 자동 공제·보강
- 기타 자재·단가표의 미완성 화면 연결
- 로그인·서버 저장·기기 간 동기화

현재 구현되지 않은 기능을 시안에 있다는 이유로 표시하지 않는다.

## 11. 완료 기준

- 기존 기능에 접근할 수 있다.
- 같은 공간의 탭 전환으로 입력과 편집 상태가 사라지지 않는다.
- 좌표·배치·계산·저장 결과가 기존 정책과 일치한다.
- 노트북에서 캔버스와 주요 명령을 사용할 수 있다.
- 작은 화면과 키보드로 주요 기능에 접근할 수 있다.
- 린트·타입 검사·테스트·빌드 결과를 기록한다.
- 실제 브라우저 검증과 발견한 문제의 재검증을 기록한다.
