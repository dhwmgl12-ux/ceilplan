# CeilPlan Domain Rules

## Purpose

이 문서는 CeilPlan 계산 엔진에서 사용하는
천장 자재 산출 규칙과 도메인 기준을 기록한다.

확인되지 않은 수치나 규칙은 추측해서 입력하지 않는다.

## 1. Current MVP Rule Strategy

CeilPlan 1차 MVP는
“공식 시공 기준을 자동 판정하는 시스템”이 아니라,
사용자가 입력한 계산 조건을 바탕으로
자재 수량과 예상 금액을 계산·정리하는 도구로 시작한다.

즉, 1차 MVP에서는 사용자가 직접 입력한다.

- M-BAR 간격
- 캐링 간격
- 석고보드 규격
- Loss(석고/금속)
- 자재 단가

CeilPlan은 이 입력값을 바탕으로 계산을 수행한다.

## 2. Base Calculation Flow

기본 계산 흐름은 다음과 같다.

기본 물량

- 현장 요소에 따른 추가/보강

* 현장 요소에 따른 공제
  = 이론 필요 수량

이론 필요 수량

- Loss
  = 구매 필요 수량

구매 필요 수량
→ 구매 단위 반올림
= 예상 발주 수량

예상 발주 수량 × 단가
= 예상 발주 금액

## 3. Input-based Rules for MVP

현재 확정된 MVP 원칙:

- 공식 기준이 불명확한 항목은 자동 기본값으로 하드코딩하지 않는다.
- 사용자가 직접 입력하도록 한다.
- 이후 공식 기준이 확보되면 추천값/기본값으로 확장할 수 있다.

## 4. Units

내부 길이 단위는 mm로 통일한다.
표시 시에는 mm / m / ㎡를 상황에 맞게 사용한다.

## 5. Materials in MVP

초기 MVP에서 다루는 주요 자재:

- 석고보드
- M-BAR
- 캐링채널
- 행거
- 클립
- 기타 부속자재(필요 시)

## 6. Feature Handling in MVP

MVP에서 지원하는 현장 요소:

- 시스템 에어컨
- 점검구
- 스프링클러
- 등박스

현재 원칙:

- 요소는 화면에 입력하고 2D 미리보기에서 표시한다.
- 요소별 계산 규칙이 명확하지 않은 경우 임의 수치를 넣지 않는다.
- 해당 항목은 “기준 미확정” 또는 “추후 확장”으로 표시할 수 있다.

즉 1차 MVP에서는
복잡한 자동 보강 계산보다
구조와 입력 흐름을 먼저 완성하는 것을 우선한다.

## 7. Loss Rule

Loss는 자재별로 사용자 입력값을 사용한다.

예:

- 석고 Loss
- 금속 Loss

Loss와 발주 반올림은 반드시 구분해서 표시한다.

## 8. Pricing Rule

가격은 공식 규칙이 아니라 회사/거래처 기준이다.
사용자가 직접 입력한다.

단가 미입력 시 0원으로 계산하지 않고
“단가 미입력” 상태로 처리하는 것이 바람직하다.

## 9. Confidence Policy

규칙 상태는 다음처럼 관리한다.

- CONFIRMED: 근거가 분명한 규칙
- INPUT_BASED: 공식값 대신 사용자 입력을 사용하는 규칙
- UNKNOWN: 아직 규칙이 정리되지 않은 항목

현재 MVP는 많은 항목을 INPUT_BASED로 처리한다.

## 10. Future Rule Expansion

추후 공식 시방서, 제조사 기준, 검산 사례가 확보되면
다음 항목을 고도화할 수 있다.

- M-BAR 기본 간격 추천값
- 캐링 기본 간격 추천값
- 석고 규격별 자동 계산
- 등박스 자재 증감 규칙
- 우물천장 규칙
- 에어컨/점검구 보강 규칙
- 구매 단위 규칙 고도화

## 11. Validation Principle

테스트 기대값은 임의로 만들지 않는다.
실제 검산 사례 또는 확정된 입력 조건을 기준으로 검증한다.
