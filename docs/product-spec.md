# CeilPlan Product Spec

## 1. Product Summary

CeilPlan은 소장, 시공회사, 견적/공무/발주 담당자가
현장 조건을 입력하면 천장 자재의 예상 필요 수량과
예상 발주 금액을 계산·관리할 수 있는 B2B 웹 서비스다.

CeilPlan은 단순 면적 계산기가 아니라,
현장 조건에 따라 자재가 어떻게 증감되는지 설명하고,
그 결과를 발주 수량과 금액까지 연결해 보여주는 도구를 목표로 한다.

## 2. Problem

기본적인 평천장 물량은 경험으로 대략 판단할 수 있지만,
실제 현장에서는 다음 요소들로 인해 계산이 복잡해진다.

- 등박스
- 우물천장
- 시스템 에어컨
- 점검구
- 스프링클러
- 기타 설비 및 돌출 요소

이 요소들 때문에 기본 수량에서
추가 / 공제 / 보강 / Loss / 발주 반올림이 발생한다.

CeilPlan은 이 과정을 정리해서
예상 자재 수량과 예상 발주 금액을 보여준다.

## 3. Target Users

주요 사용자는 직접 시공하는 작업자보다 다음 사용자다.

- 현장소장
- 천장/인테리어 시공회사
- 견적 담당자
- 공무 담당자
- 자재 발주 담당자

대표 사용 흐름:
견적 담당 입력 → 소장 검토 → 발주 담당 활용

## 4. Core Value

CeilPlan은 다음 질문에 답해야 한다.

- 이 현장에 자재를 얼마나 발주해야 하는가?
- 어떤 현장 조건 때문에 자재가 늘거나 줄었는가?
- Loss와 발주 반올림까지 적용하면 최종 발주 수량은 얼마인가?
- 회사 단가를 적용하면 예상 금액은 얼마인가?

## 5. MVP Scope

초기 MVP는 다음 범위로 제한한다.

포함:

- 프로젝트 생성 / 목록
- 직사각형 공간 1개
- M-BAR + 석고보드 천장
- 현장 기본 정보 입력
- 천장 계산 조건 입력
- Loss 입력
- 자재 단가 입력
- 2D SVG 미리보기
- 예상 자재 산출 요약
- 상세 자재 산출 표
- 예상 발주 금액
- 계산 근거 표시

현장 요소:

- 시스템 에어컨
- 점검구
- 스프링클러
- 등박스

초기 제외:

- 3D 보기
- 로그인
- DB
- PDF
- 공유 URL
- 실시간 시세 연동
- 다중 공간
- 다른 공종

## 6. Key User Flow

1. 프로젝트 생성
2. 현장 기본 정보 입력
3. 천장 계산 조건 입력
4. Loss 및 자재 단가 입력
5. 현장 요소 입력
6. 2D 미리보기 확인
7. 예상 자재 산출 요약 확인
8. 상세 산출 내역 확인
9. 예상 발주 금액 확인
10. 계산 근거 확인

## 7. UI Direction

MVP UI는 다음 구조를 따른다.

- 좌측: 현장 입력 폼
- 가운데: 천장 2D 미리보기
- 우측: 산출 결과

우측 산출 결과는 다음 순서로 구성한다.

1. 예상 자재 산출 요약 카드
2. 상세 자재 산출 표
3. 예상 발주 금액
4. 계산 근거 및 안내

## 8. Result Policy

결과는 총수량 하나만 보여주지 않는다.
자재별로 다음을 구분해서 표시한다.

- 기본 수량
- 추가/보강 수량
- Loss
- 발주 반올림
- 최종 발주 수량
- 단가
- 예상 금액

Loss와 발주 반올림은 구분해서 보여준다.

## 9. Price Policy

전국 평균 시세를 정답처럼 제공하지 않는다.
회사가 사용하는 자재 단가를 사용자가 직접 입력한다.

예상 발주 수량 × 사용자 단가
= 예상 발주 금액

초기 금액 범위는 자재비 중심이다.

## 10. Safety / Responsibility

CeilPlan은 구조 안전 판단이나 시공 승인 도구가 아니다.
예상 물량 산출 및 발주 지원 도구다.

실제 시공은 설계도면, 시방서, 제조사 기준,
현장 조건 및 담당자 판단을 우선한다.

## 11. Future Expansion

MVP 이후 검토 가능한 기능:

- 회사 공통 단가표
- 브라우저 저장 개선 / DB 저장
- PDF 산출서
- 프로젝트 공유
- 비정형 공간
- 다른 천장 공법
- 벽 타일 등 타 공종 확장
